Pattern : Two Pointer

Problem : Remove Duplicate

Description : 
   Given a sorted integer array nums, remove the duplicates in-place such that
   each unique element appears only once. The relative order of the elements
   should be kept the same.


Example:
Input: nums = [1,1,2,2,3,4,4,5]

Output:
Unique Elements: [1,2,3,4,5]
Count = 5


Approach : Two pointer

Language : C++


     #include <iostream>
     #include <vector>
     using namespace std;

       int removeDuplicates(vector<int>& nums) {

       if (nums.size() == 0)

        return 0;

        int i = 0;

        for (int j = 1; j < nums.size(); j++) {

        if (nums[j] != nums[i]) {

            i++;

            nums[i] = nums[j];
        }
    }

    return i + 1;   // number of unique elements
}


Time Complexity: O(n)
Space Complexity: O(1)
